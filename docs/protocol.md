# Protocol

`yllama-runner` supports the compatibility protocol 1 and negotiated protocol 2
described in [runner-protocol.md](runner-protocol.md). The complete protocol 2
client contract is [yllmd-protocol-v2-migration.md](yllmd-protocol-v2-migration.md).

The runner protocol is internal to local supervisors such as `yllmd`. It is not
a public client API.
