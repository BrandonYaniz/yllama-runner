# yllama-runner 2026.05.31-beta.1

> Historical note: this document describes the JSONL implementation at that
> release. Commit `742b19e` later replaced it with the compact binary protocol.
> It is preserved as release history, not current protocol documentation.

## Compatibility

- Release version: 2026.05.31-beta.1
- Runner protocol version: 1

## Breaking Changes

- None.

## Deprecations

- None.

## Changes

- Added a stdio JSON Lines runner around llama.cpp.
- Added configure, generate, cancel, and shutdown commands.
- Added streamed delta events and token usage reporting.
- Added support for raw prompt input and role/content message input.
- Added stop sequence handling that withholds matched stop text from streamed deltas.
- Added single active request handling and cancellation for active generation.

## Fixes

- Kept llama.cpp diagnostics on stderr while preserving stdout for JSONL protocol events.
- Cleared llama context memory between generation requests.
- Fixed stop sequence flushing so matched stop text is not emitted at completion.

## Build and Packaging

- Requires a local llama.cpp build or install.
- Installs `yllama-runner` under `libexec` by default.
- Supports opt-in model-backed smoke testing with a local GGUF model.
- Documents macOS beta verification with install rpath handling for shared llama.cpp libraries.
