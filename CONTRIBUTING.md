# Code of Conduct

## Purpose

`yllama-runner` is a small open source project focused on providing a simple local inference runner around llama.cpp.

The project welcomes good-faith contributions, bug reports, documentation fixes, testing, packaging work, and technical discussion.

This Code of Conduct exists to keep the project useful, focused, and respectful.

## Expected Behavior

Participants are expected to:

- Treat other people with basic respect.
- Keep discussion focused on the project.
- Give and receive technical criticism in good faith.
- Assume honest mistakes before assuming bad intent.
- Be clear when reporting bugs, proposing changes, or reviewing code.
- Respect maintainer decisions about project scope, architecture, and priorities.

Strong disagreement is allowed. Personal attacks are not.

## Unacceptable Behavior

The following behavior is not acceptable in project spaces:

- Harassment, intimidation, threats, or abuse.
- Personal attacks, insults, or sustained hostility.
- Discrimination or derogatory comments directed at a person or group.
- Sexualized comments, imagery, or unwelcome attention.
- Publishing someone else's private information without permission.
- Spam, trolling, or repeated off-topic disruption.
- Bad-faith issue filing, pull requests, or review comments.
- Attempts to derail the project with unrelated political, personal, or ideological arguments.
- Any conduct that would reasonably make participation unsafe or needlessly hostile.

## Scope

This Code of Conduct applies to all project-controlled spaces, including:

- GitHub issues.
- GitHub pull requests.
- GitHub discussions, if enabled.
- Project documentation.
- Official project communication channels, if any are added later.

It also applies when someone is clearly representing the project in public.

## Enforcement

Maintainers may take reasonable action to protect the project and its contributors.

Actions may include:

- Asking a participant to change their behavior.
- Editing, hiding, or deleting comments.
- Closing issues or pull requests.
- Rejecting contributions.
- Temporarily limiting participation.
- Permanently banning a participant from project spaces.

Maintainers should apply this Code of Conduct in good faith and in proportion to the situation.

## Reporting

Problems may be reported to the project maintainer.

For non-sensitive issues, open a GitHub issue.
